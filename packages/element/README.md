# @scrollframe/element

The `<scroll-sequence>` custom element: scroll storytelling for any framework (Angular, Vue, Svelte, Astro) or plain HTML.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@scrollframe/element@0.2/dist/scroll-sequence.css" />
<script src="https://cdn.jsdelivr.net/npm/@scrollframe/element@0.2" defer></script>

<scroll-sequence src="/sequence/manifest.json" alt="Describe the scene">
  <h1>Your headline</h1>
</scroll-sequence>
```

See the [scrollframe documentation](https://github.com/JavierCornejoLeal/scrollframe#any-framework-or-plain-html-scroll-sequence).
